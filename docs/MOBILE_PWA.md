# Mobile & PWA

Installable Tetris WebGPU for phones and desktops: web manifest, versioned service worker, touch controls, safe-area layout, and optional fullscreen.

## Install (Chromium)

1. Run a production build: `npm run build:all` (or `npm run build` after `npm run asbuild:release`).
2. Serve `/dist` over HTTPS (or `npm run preview` locally).
3. Open the app, then use **Install** in the browser menu (or the install banner).
4. Run Lighthouse **Progressive Web App** — expect **Installable** when icons and `sw.js` are present.

Artifacts:

| Path | Role |
|------|------|
| `public/manifest.webmanifest` | App name, theme, icons |
| `public/icons/icon-*.png` | Generated by `npm run pwa:icons` (prebuild) |
| `dist/sw.js` | Post-build precache (`npm run postbuild`) |
| `dist/sw-build.json` | Build id + precache list (debug) |

The service worker uses a **content hash build id**. Old caches are deleted on activate. The post-build script **fails** if any precache file is missing, so partial deploys are not cached.

### Offline play

1. Load the app once online (install optional).
2. DevTools → Application → Service Workers — confirm `sw.js` active.
3. Enable **Offline** in the Network panel.
4. Reload — shell, WASM (`release.wasm`), textures, and JS should load from cache.
5. Tap **START** — marathon runs with **procedural backgrounds** (video URLs fail gracefully offline).
6. WebGL2 fallback is fine when WebGPU is unavailable on mobile.

Audio still requires a **user gesture** (START, touch control, or canvas tap) before sound plays.

## Touch playtest checklist

Use a real phone or Chrome DevTools device emulation with touch enabled.

### Layout & chrome

- [ ] Notch / home indicator: UI does not sit under system bars (`viewport-fit=cover`, `env(safe-area-inset-*)`).
- [ ] Portrait: panels stack; playfield remains visible; touch buttons clear of swipe zone.
- [ ] Landscape (short height): side panels scroll; smaller touch targets still ≥ 44px effective.
- [ ] **FULLSCREEN** button toggles Fullscreen API where supported; hidden when unsupported.
- [ ] Offline banner appears when network is off; disappears when back online.

### Touch controls

- [ ] Overlay appears on coarse pointer / touch devices; hidden on desktop mouse (`min-width: 900px` + fine pointer).
- [ ] **HOLD**, **← ↓ →**, **↺ ↻**, **⤉ DROP**, **⏸** respond during active play.
- [ ] **⏸** works when paused / before start.
- [ ] Hold **←** / **→** / **↓** — DAS-style repeat after ~130ms.
- [ ] Swipe on center playfield: horizontal = move, down = soft drop, up = hard drop.
- [ ] First touch unlocks audio (no console errors from `AudioContext`).
- [ ] Haptic pulse on supported Android (`navigator.vibrate`); no crash on iOS (API absent).

### Gameplay

- [ ] START begins game; pieces fall; line clears work.
- [ ] Pause menu opens from **⏸** or keyboard; resume works.
- [ ] Sprint / Ultra mode selectable (marathon default for offline endless).
- [ ] WebGL2 path: add `?renderer=webgl2` if WebGPU fails — touch + offline still work.

### PWA

- [ ] Manifest linked; theme color matches UI.
- [ ] Add to Home Screen → standalone launch (`pwa-standalone` layout).
- [ ] After update deploy, refresh shows update toast when new `sw.js` is waiting.

## Development

```bash
npm run dev -- --host 0.0.0.0 --port 5173
# Service worker is PROD-only; test offline with:
npm run build:all && npm run preview
```

Touch styles live in `src/input/touchControls.ts` (injected) and `css/mobile.css` (safe-area, landscape, banners).

## Files

- `src/pwa/registerServiceWorker.ts` — registration + update toast
- `src/pwa/offlineBanner.ts` — offline indicator
- `src/pwa/fullscreen.ts` — fullscreen toggle
- `src/input/touchControls.ts` — buttons, swipe, haptics
- `scripts/generate-sw.mjs` — versioned precache manifest
- `scripts/generate-pwa-icons.mjs` — PNG icons (ImageMagick)
